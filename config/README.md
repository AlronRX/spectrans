# SPECTRANS

Корпоративный сайт ООО «СПЕЦТРАНС».

## О проекте

Проект разрабатывается в рамках учебной практики.

## Основной функционал

- Каталог спецтехники
- Услуги предприятия
- Приём заявок клиентов
- Калькулятор стоимости аренды
- Административная панель

## Технологии

- Python
- Django
- HTML, CSS, JavaScript
- SQLite / PostgreSQL
- Flutter
- Git и GitHub

## Статус проекта

В разработке.
